Getting started

The Scribe uses Discord slash commands. Type / in the message box and select a command from Discord's command picker.

1. Add the bot

Invite The Scribe to a server where you have permission to add bots. Review the permissions Discord displays during installation.

2. Start a round

Use /quote to display a quote. You can choose a category or leave it blank for a random category.

3. Guess the source

Use /guess answer: followed by the film, series, game, anime, or book you think the quote comes from.

4. Need a clue?

Use /hint to reveal the clue for the current round. A hint can only be revealed once per round in that channel.

Submitting a quote

Community submissions help expand the quote pool.

Use /submitquote and fill in all four fields:

  • quote — the exact line players will see.
  • source — the film, show, game, anime, or book it comes from.
  • category — choose one of the four available categories.
  • hint — a clue to help players identify the source.

The current command allows up to three submissions per user in a 60-second period. A successful submission is added to the quote pool and can appear in future /quote rounds.

Daily quote setup

Server administrators can choose where the daily challenge is posted.

  1. Go to the text channel where you want daily quotes to appear.
  2. Run /setdailychannel in that channel.
  3. The bot confirms the selected channel. Daily posts are scheduled for 9:00 AM UK time.

The daily scheduler depends on The Scribe being online and retaining access to the selected channel. If a post does not appear, check the bot status page and support server.
